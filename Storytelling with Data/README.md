📌 Project Overview

In this project, I analyzed retail sales and returns data to identify the root causes of high product return rates at a SuperStore. The objective was to help executive leadership understand why customers were returning products and provide actionable recommendations to reduce return volume and improve operational performance.

Using data visualization and dashboard development techniques, I combined sales and returns datasets, calculated return rates, and examined return behavior across products, customers, geographic regions, and time periods. The final deliverable included an interactive dashboard designed to monitor return trends and support data-driven decision-making.

🎯 Business Problem

The SuperStore experienced a high volume of returned orders, leading to increased operational costs and reduced profitability. Leadership needed insights into the drivers of returns and a system to monitor return patterns over time.

Key business questions included:

What is causing the high number of returned orders?
Which products have the highest return rates?
Which customers frequently return items?
Are returns concentrated in specific geographic regions?
Do returns increase during certain times of the year?
How can the business reduce return volume?

🔎 Key Insights
High return rates were concentrated within specific product categories
Certain customers demonstrated frequent return behavior
Returns were more common in specific geographic regions
Seasonal patterns influenced return volume
Some high-sales products had disproportionately high return rates
💡 Business Recommendations

Based on the analysis, the following recommendations were provided:

Improve quality control for high-return products
Monitor customers with frequent return behavior
Review return policies for high-risk product categories
Track seasonal return patterns
Use dashboards to monitor return performance continuously
